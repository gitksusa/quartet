# ADR-007: Phase 0bの固定セクション表示切替

## ステータス

採用（PR10実装前の方針確定）。ADR-005のHP表示トグル補足を置き換える。

## 背景

固定テンプレートのLite CMSと、後続の汎用ブロックエディタの範囲が混在していた。PR10の表示切替範囲を確定する。

## 決定

- 管理対象は共通セクションIDの12個。`hero` はページの基点として常時表示・PR10ではOFF不可とする。
- 他11個はON/OFF可能。`reservation` / `access` は重要だが、PR10では必須固定にしない。
- HP内セクションは `tenant_sections.is_visible`、求人ページ本体の公開は `tenants.is_recruit_enabled` が担う。`recruit_cta` はHP内の導線として分離する。
- PR10はowner認可付きの取得（visible / hidden双方）・管理画面表示・表示状態の切替と保存まで。内容編集・画像・自由配置・並べ替えUI・公開HP描画・mood反映・プレビュー・下書き／公開分離は含めない。

## 帰結

固定テンプレートの構成を保ちながら、オーナーが必要な情報を選択できる。重要な導線をOFFにできる点は許容する。初期値・未作成行の扱いはPR10の実装設計で確定し、このADRではDB変更やRPC実装を行わない。
