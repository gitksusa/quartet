# ADR-003: フェーズ2でのAWS移行計画

## ステータス
計画済み（フェーズ2で実行予定）

## コンテキスト
フェーズ1（Fly.io + Supabase）からフェーズ2（AWS ECS + RDS）への
移行をいつ・どのように行うかを事前に定義しておく。

## 決定事項
以下のトリガー条件を満たした時点でAWSへの無停止移行を実施する。

## 移行トリガー条件
- テナント数が10〜50店舗を超えた時
- オートスケールの要件が発生した時
- RDSのMulti-AZ構成による高可用性が必要になった時

## 移行手順（概要）
1. TerraformでAWS ECS FargateとRDS PostgreSQLを構築する
2. SupabaseのデータをRDSにマイグレーションする
3. 新旧環境を並行稼働させてトラフィックを段階的に切り替える
4. 旧環境（Fly.io・Supabase）を停止する

## 移行時の設計原則
- サービスを停止せずに移行することを原則とする
- Terraformのコードを修正することで環境を再現する

## フェーズ2の追加技術
- AWS SSM Session Manager（踏み台廃止・セキュアなアクセス）
- Prometheus + Grafana（メトリクス可視化）
- RDSスナップショット（定期バックアップ）
