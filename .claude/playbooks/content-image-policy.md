## Authority

このドキュメントは、Quartet における「コンテンツ画像の分類・利用・表示」の Source of Truth である。

## 背景

美容・医療系のWebサイトでは、雰囲気を演出する装飾画像と、実際の施術結果を主張する画像を混同して表示すると、景品表示法上の「優良誤認」リスクが発生する。法務リスクの本質は「施術写真かどうか」ではなく「施術結果を主張しているかどうか」にある。店舗内観・スタッフ写真・施術風景は実写真であってもリスクは比較的低く、Before/After・症例写真は厳密な運用が必要になる。この違いに基づき、画像を3分類する。

## 画像分類

### 1. 背景・雰囲気画像

- 用途：セクションの背景、装飾、雰囲気演出
- 取得元：Unsplash API / Pexels API(無料・商用利用可)、またはテナント自身が用意した装飾用画像
- 禁止：施術結果・Before/After表現として使用すること
- ジャンル選択：ネイル・整体・ヘアー・マッサージ・リラクゼーション等のジャンルボタンから、適した装飾画像を選択できるUIとする

### 2. 実写コンテンツ

- 用途：店舗の実態を伝える写真(施術結果の主張を含まない)
- 対象：スタッフ写真・店舗写真・設備写真・施術風景
- 取得元：**テナント自身がアップロードした実写真のみ**(Unsplash/Pexels等のストック素材は使用不可)
- 優良誤認リスク：比較的低い(実態の提示であり、効果・結果を主張するものではない)

### 3. 施術結果画像

- 用途：施術の結果・効果を示す画像
- 対象：Before/After・症例写真
- 取得元：**テナント自身がアップロードした実写真のみ**
- 優良誤認リスク：**高い**。誇張表現を行わず、実際の施術結果と一致していることを前提とする
- 要件：出典管理(誰がいつ撮影・アップロードしたか)、将来的に被写体の同意取得記録も紐付けられる設計にしておく

## 管理画面要件

- 画像登録時に上記3分類のいずれかを**必須選択**とする
- UI上で3種類を明確に区別して表示する(タブ分け、ラベル表示等)
- 同一の画像アップロードフローで複数分類を混在させない
- 「施術結果画像」を選択した場合は、追加の確認・警告表示を検討する(将来拡張)

## Unsplash/Pexels API 統合(実装メモ)

- 両APIとも無料・商用利用可。「背景・雰囲気画像」の用途に限定して使用する。
- Canva APIは見送り(マルチテナント動的生成・SEO/LLMO観点で不向き)。
- 実装はPhase 0のテンプレート構成(5パターン)に合わせて、ジャンル別の画像セットを用意する。
